The clean final canvas is the production byte oracle; the development export regression separately verifies its underlying authoritative frame.
- **C**: fresh development Chrome profiles at `http://127.0.0.1:5173/?scene-checks`, same engine/GPU, actual WebGL2. Existing export/preset/import/polish/performance harnesses rerun with fresh `pss20-*` evidence prefixes. Performance: 1440×900/DPR1. Polish: 1440×900, 1024×768, 768×900; exports 1500×1100/DPR1/2.
- **Independent decode**: Pillow 12.3.0 reads actual completed downloaded PNG files and compares exact native dimensions and every RGBA byte to the saved authoritative frame (or production clean canvas). 56 files pass, alpha only0/255, all hidden RGB zero. A separate square-stamping oracle compares all decoded 2px outline pixels. Imported frame oracle: 110 checks /20 fresh native frames.
- **Code** means source inspection supplements observed tests; it never substitutes for required browser checks. Files were read under domain/store, all inspectors, scene/camera/light/framing/capture/presentation/shadow owners, import, export and persistence. Native `samples=0` overrides the hidden context's reference antialias option; geometry is directly rasterized at W×H. No screenshot downsampling supplies pixels.
